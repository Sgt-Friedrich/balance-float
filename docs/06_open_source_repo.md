# 开源代码仓库说明

## 项目仓库
- GitHub: https://github.com/ChengjinLii/studyhub

## 项目说明
StudyHub 是一个面向高校学习场景的 AI 学习辅助平台，核心能力为 StudyHub Agent，用于实现检索增强、证据约束生成与学习过程辅助。

## 仓库内容结构（概览）
- frontend/：前端交互界面
- backend/：后端服务与API
- agent/：智能体核心逻辑（Query Planner / RAG / Memory / Safety）
- docs/：论文与实验材料
